# 组会文献汇报 Skill

把论文 PDF 或 Word（`.docx`）制作成组会风格的可编辑 PPTX。默认采用2026-09-17模板：4:3白底、楷体与Times New Roman，按“科学问题 → 原图证据 → 必要的方法/模型讲解 → 回答”组织内容。图页右栏解读15pt、底部16pt，支持原生比较表和整页原理讲解。

## 安装

在 Codex 中提供本仓库中的 `artifact-template-lab-journal-club` 文件夹链接，并要求安装到个人 skills 目录、检查运行依赖。保留整个文件夹结构；仅复制 `SKILL.md` 不足以运行。

## 使用

在 Codex 任务中附上论文 PDF 或 DOCX，然后输入：

> 请用 $artifact-template-lab-journal-club，把这篇论文做成中文文献汇报 PPT，汇报约 20 分钟。

也可以指定总页数、重点结果或需要修改的页面。旧 `.doc` 文件需先转换为 `.docx`。

## 运行条件与范围

- 依赖当前 Codex 提供的 Presentations 技能、workspace runtime 及其 Node/Python 和相关库；安装后先让 Codex 检查依赖。
- 当前在 Windows Codex 环境验证；其他环境需重新验证生成、字体与渲染工具。
- 每篇新论文首次使用时必须真实核读正文、研究设计、主要结果和图注，核对科学结论与原图证据，并检查最终幻灯片。
- 通过缓存论文解析、复用排版脚本与原图减少重复工作；不承诺固定额度或节省比例。
- 教学插图按需使用，不默认批量生成。模板的59页/5个问题是参考实例，输出规模按新文章与时长决定。

## 文件与论文

仓库保存技能、脚本和既有汇报的样式参考（`assets/reference.pptx` 保留参考汇报原件及示例内容），不包含待汇报的新论文。参考内容不作为新论文的证据。

请将新论文、补充材料、解析缓存和生成的汇报保存在本地 Codex 任务中，不要提交到本仓库。`.gitignore` 只能减少误提交，提交前仍应核对文件清单。
