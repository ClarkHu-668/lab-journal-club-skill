# 新版组会文献汇报样式

主参考为 **2026-09-17**《生酮饮食通过脂质而非酮体介导肠道肿瘤发生》，59页，完整保存在 `assets/reference.pptx`。对应论文用于校准选图和讲述方法。六份旧稿仅为历史来源，样式冲突以新稿为准；标题、姓名和科学内容不成为后续文章默认内容。

## 视觉规则

画布4:3，10×7.5英寸（960×720 px）；白底黑字，中文楷体、西文Times New Roman。少量宋体及主题默认字体不覆盖主字体。

| 元素 | 默认字号与处理 |
|---|---|
| 封面标题、问题与回答 | 28 pt；红标签、黑色问题或回答，粗体 |
| 作者与研究背景标题 | 36 pt蓝色；资料不足时省略人像/履历 |
| 背景或原理页标题 | 24 pt蓝色，可分两行 |
| 文章思路由来标签 | 20 pt黑色，黄色高亮 |
| 主干图标题/机制主干/问题 | 24/16.5/14 pt；红标题、黑主干、右栏细红框 |
| 英文Figure/Extended Data标题 | 18 pt，Times New Roman，左上黑字 |
| 图左文右的中文解读 | **15 pt**，按实验比较分段 |
| 图上文下的中文解读 | **16 pt**，通常2–4个简短段落 |
| 局部定义或提示 | 11–14 pt，仅少量，不替代主讲解 |
| 结尾评价与启发 | 蓝色小标题、黑色正文，过长拆页 |

红色FF0000用于问题标签、关键差异及少量边注；蓝色0000FF/0070C0用于背景和总结标题；黄色FFFF00用原生字符高亮突出结果句。新版不再默认旧版11pt密集长图注。

## 封面、背景与比较

- 封面（第1页）：上方中文标题，中上部大幅新论文题录图，右下汇报人和日期。题录图从y≈1.25英寸开始、高≈3.83英寸；长标题需预留空间避免覆盖。
- 作者与背景（第2页）：蓝色标题，人物/单位与研究领域介绍；只采用可核实且有助理解的资料。
- 缘起（第3/11页）：黄色小标题，下方示意图。采用已知背景、矛盾/缺口和核心问题的信息结构，不强制四列彩卡。
- 比较表（第4/5/14页）：文献或实验条件对照；用原生表格、浅灰蓝填色，少量浅黄行强调。字段由比较目的决定，密表拆页，不照搬旧型号、IF或肿瘤清单。

## 原图证据与教学插页

- `figure-bottom`：标题约x=0.19,y=0.10,w=9.52,h=0.63英寸；图在y≈0.81–4.96；底部解读x≈0.21,y≈5.15,w≈9.5,h≈2.15。图片等比居中。第26/29/31/36页为范例。
- `figure-right`：左图槽x≈0.13,y≈0.83,w≈6.75,h≈6.52；右栏x≈7.10,y≈0.85,w≈2.77,h≈6.42。第19/33/38/51–55页为范例。设计图和结果图可分为独立的原图块。
- 解读写清panel对应、组别/干预、结果及有限解释。n、P、时间点只在影响解释时随段列出；不要塞入完整图注。新版典型图页约100–130中文字只是密度参考，不是字数硬限制。
- 少量边注解释当前图的阅读障碍，放在留白区；拥挤时改为独立教学页。
- `explainer`（第9/10/17/20/21/28/30/32/37/46页）：一页讲一个模型/方法。新版常用近满版插图、清晰流程和核心句；可用核实的图片或可编辑文字步骤。图内已有标题时不再叠标题。讲清“改哪里、何时改、如何验证、读出是什么”。
- 模型解释插在对应实验附近。如第19页证据→第20/21页教学→第22页回证据，允许有目的地重复。

## 问题、回答与收尾

问题页13/25/40/43/50，回答页24/39/42/49/56：居中大字、留白；回答保留问题并限定模型/条件。问题数由新论文决定。

主干图第12/58页：左侧纵向结果链和向下箭头，右侧对应问题。通常一页2–5步，更多则拆页；红框高度随内容增长。机制模型第57页总结生物关系，主干回顾总结证据如何回答问题，二者用途不同。

第59页评价、局限和启发沿用蓝色小标题；原页存在重叠，新稿应拆为“评价与局限”“研究启发”或缩短内容。第58页问题红框不足、部分页边注越界同样不可照搬。

## 复现范围

复现字体、颜色、图文层级和教学节奏，同时修正局部越界、遮挡和不准确标签。彩色教学插图不等于每篇都要生成全套新插画；先复用本篇已有示意或简洁可编辑说明，按需生成复杂插图。几何/字号事实在 `compact-style.json`，常规制作无需全量加载。
